# contempt/validation

[![CI](https://github.com/contempt-framework/validation/actions/workflows/ci.yml/badge.svg)](https://github.com/contempt-framework/validation/actions/workflows/ci.yml)

Compiled structural boundary validation. Violations are values, never exceptions.

> This repository is a **read-only split** of the Contempt monorepo.
> Issues and pull requests belong in
> [contempt-framework/contempt](https://github.com/contempt-framework/contempt).

## Installation

```bash
composer require contempt/validation
```
